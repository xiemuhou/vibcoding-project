## 二、技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| 前端 | **Vue 3 + Element Plus** | 参考系统同样使用 Vue 3，组件库成熟，网格/弹窗/表单开箱即用 |
| 后端 | **Python Flask** | 轻量、开发快，openpyxl 处理 Excel 导入导出 |
| 数据存储 | **SQLite** | 零安装、单文件；支持并发写入和事务，远优于 Excel 直读（详见下方对比） |
| 认证 | **JWT Token** | 无状态认证，配合配置文件管理账号 |
| 构建 | **Vite** | 快速构建，生产模式打包后由 Flask 静态托管 |

### 为什么不像参考系统那样直接读 Excel？

参考系统(YSGB·Plan)疑似采用前端直读 Excel 方案，适合**只读展示**场景。但 IP 管理有频繁写入需求：

| 对比项 | 参考系统（生产日报） | IP管理系统 |
|--------|-------------------|-----------|
| 数据操作 | 只读展示为主 | 频繁占用/释放/编辑 |
| 并发场景 | 单人编辑、多人查看 | 多人可能同时操作 |
| 数据一致性 | 日报级别，容忍延迟 | 不能重复分配同一IP |

**结论**：Excel 仅作为初始导入源和导出备份格式，运行时使用 SQLite。

## 四、功能模块设计

### 4.1 登录认证

- 单管理员账号，存储在 `config.yaml` 中（密码 bcrypt 哈希）
- 登录后签发 JWT Token，有效期 8 小时
- 不提供注册功能，修改密码需编辑配置文件
- 前端路由守卫：未登录自动跳转登录页

```yaml
# config.yaml
server:
  host: "0.0.0.0"
  port: 5000

auth:
  jwt_secret: "your-secret-key-change-this"
  token_expire_hours: 8
  username: "admin"
  password: "$2b$12$xxxxx"     # bcrypt 哈希

data:
  excel_path: "./data/IP地址信息汇总.xlsx"
  db_path: "./data/ip_manager.db"
```

提供密码生成工具：`python generate_password.py <你的密码>`

## 五、数据库设计

精简为两张表（移除了操作日志表）：

### subnets 表

```sql
CREATE TABLE subnets (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    cidr        TEXT NOT NULL UNIQUE,    -- "10.10.155.0/24"
    name        TEXT NOT NULL,           -- "白云区5F PC设备"
    sort_order  INTEGER DEFAULT 0        -- 显示排序
);
```

### ip_addresses 表

```sql
CREATE TABLE ip_addresses (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    subnet_id    INTEGER NOT NULL REFERENCES subnets(id),
    ip_address   TEXT NOT NULL UNIQUE,   -- "10.10.155.3"
    ip_suffix    INTEGER NOT NULL,       -- 3
    status       TEXT NOT NULL DEFAULT 'free',  -- "free" / "occupied"
    department   TEXT DEFAULT '',         -- 使用部门
    username     TEXT DEFAULT '',         -- 使用人
    device       TEXT DEFAULT '',         -- 使用设备
    device_model TEXT DEFAULT '',         -- 设备型号
    mac_address  TEXT DEFAULT '',         -- MAC地址
    location     TEXT DEFAULT '',         -- 位置
    remark       TEXT DEFAULT '',         -- 备注
    updated_at   DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_ip_subnet ON ip_addresses(subnet_id);
CREATE INDEX idx_ip_status ON ip_addresses(status);
```

## 六、API 设计

精简后的接口列表：

### 认证（2个）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/login` | 登录，返回 JWT Token |
| GET | `/api/me` | 获取当前用户信息 |

### IP 管理（6个）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/subnets` | 获取所有子网段（含统计数） |
| GET | `/api/subnets/{id}/ips` | 获取某子网段全部 IP |
| GET | `/api/ips/{id}` | 获取单个 IP 详情 |
| PUT | `/api/ips/{id}/occupy` | 占用 IP（提交使用信息） |
| PUT | `/api/ips/{id}/release` | 释放 IP（清空使用信息） |
| PUT | `/api/ips/{id}` | 编辑 IP 信息 |

### 辅助（3个）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/search?q=keyword` | 全局搜索 |
| GET | `/api/export` | 导出 Excel |
| POST | `/api/reimport` | 重新从 Excel 导入（覆盖数据库） |

**共 11 个接口。**
